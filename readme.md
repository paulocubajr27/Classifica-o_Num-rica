Descrição: 
*Este  projeto foi desenvolvido em Python com o bjetivo de gerar números inteiros aleatórios, classificá-los de acordo com suas propriedades matemáticas e armazená-los em diferentes arquivos de texto. 
*O programa gera um número aleatório entre -1000 e 1000 até que o número 0 seja sorteado (provocando quebra no laço de repetição principal). 

Durante a execução, os números são classificados em 4 categorias e armazenados em vetores:
*Números Pares
*Números Ímpares
*Números Primos
*Números Perfeitos

Após a classificação, os vetores são ordenados utilizando o algoritmo Merge Sort e seus valores são gravados em arquivos .txt:
*Pares.txt
*Impares.txt
*Primos.txt
*Perfeitos.txt

Tecnologias Utilizadas:
*Python 3
*Biblioteca Padrão random
*Arquivos de Texto .txt
*Algoritmo de Orgenação Merge Sort
